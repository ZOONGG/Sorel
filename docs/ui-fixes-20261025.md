# Sorel: UI fixes and verified Genesis 9.10.1 build

Base: Sorel 1.0.0, 68ecade97bf66f0d22cc1bf5824b0a5baccffc02. Separate worktree: sorel-ui-fixes-20261025. No performance experiment changes were imported.

## Changes

- Switching a package now refreshes counters without clearing and repopulating the visible package rows. Scroll position, row containers and neighboring switches remain intact.
- SmoothToggleSwitch uses the checked position immediately for initial binding and recycled rows. Its 150 ms transition runs only through OnToggle, from the current thumb position, and respects reduced-motion settings. Filters and language refreshes do not replay enabled-state animations.
- Import summaries reset after five seconds. A newer status cancels that reset, and an active launch/game prevents it from replacing game status. Old launch-status resets are cancelled when an import summary takes ownership. The same reset is used after catalog installation.
- The profile UI shows DisplayLabel (name and Minecraft version). DetailLabel remains available to existing diagnostics; profile identity, selection and launch semantics are unchanged.
- The settings language selector uses the exact same popup and language options as the header. Popup placement follows the clicked button. Scrolling its list no longer triggers the settings ComboBox closure path. The hidden ComboBox remains the existing selection/localization state source.
