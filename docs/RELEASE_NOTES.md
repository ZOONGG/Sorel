# Sorel v1.0.1

Windows x64 maintenance update through the existing Velopack stable channel.

- Fixed switches replaying animations in neighboring package rows.
- Import notifications return to Ready after five seconds without overwriting newer messages.
- Launcher profiles show their name and Minecraft version without internal identifiers.
- Settings uses the header language menu; scrolling no longer closes the language list.
- Added offline-verified Genesis 9.10.1 build 23FDDB13; native bridge and adapter bytes are unchanged.
- Veyra catalog refreshes automatically from published stable ZOONGG/Sorel-Veyra releases, with official SHA-256 verification. Installed packages are not silently replaced. Offline checks keep available entries and report that freshness could not be verified.
- Bundled Veyra 1.0.1 and Cosmetics 1.3.2 are unchanged. Performance-experiment changes are excluded.

Installed Sorel 1.0.0 receives this update through Velopack stable. Portable ZIP does not support integrated updates. No user data migration or game-setting changes. Original licenses and attribution are preserved.
